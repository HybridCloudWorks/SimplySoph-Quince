# WhatsApp Activation Review

The production WhatsApp sender is online. WhatsApp operates independently of the pending SMS A2P campaign. International guests receive a household-specific private website link; replying in WhatsApp does not submit an RSVP or sign into the website.

## Consent And First Invitations

WhatsApp is optional and separate from email and SMS. Guests with a private invitation can open My Account, enter an international-format phone and language, and explicitly request WhatsApp updates. They must then send START from that phone to verify it. Saving a form alone never enables sending.

For a guest who has not received an invitation yet, the organizer can record explicit WhatsApp permission in Notion: WhatsApp Phone, Language (en/es), Consent, Consent Date, Consent Source and Consent Version. Record actual evidence, not an inferred opt-in. Ask the guest to read /whatsapp/ and send START to +16827868002. A matching consent record and verified incoming message are required before the admin sender includes them. Merely adding a number is insufficient.

STOP/BAJA blocks WhatsApp sends locally even during Notion outages. Pending changes remain blocked until projection succeeds. Admin Retry Sync recovers failed projections. Phone changes require new verification. Shared phones are deduplicated per campaign.

## Templates

Four text templates were submitted to Meta on September 28, 2026: invitation_en, invitation_es, reminder_en, reminder_es. All were submitted as MARKETING. Current approval must be checked through the Content API before activation. The first follow-up check showed three pending and reminder_es rejected with an unknown rejection reason; rejected templates must not be used.

Templates use one variable: the private household URL generated by the server. Public examples contain no real invitation tokens. Admin drafts encrypt private URLs at rest, bind them to the active invitation generation, and require fresh consent and recipient review before dispatch. Failed or uncertain attempts are not automatically resent.

Meta currently blocks marketing-template delivery to US numbers. A US owner can test verified inbound opt-in/help/opt-out replies; full international invitation delivery needs a separately authorized eligible non-US test recipient. Do not classify invitations as utility to bypass this restriction.

## Configuration And Acceptance

Runtime uses the existing Twilio account, a restricted API key, and pinned Auth Token for signatures. Configure WHATSAPP_FROM=+16827868002, WHATSAPP_TEMPLATES_JSON, WHATSAPP_ENABLED and WHATSAPP_ACTIVATION_REVIEWED separately from SMS. Activation stays off until provider approval and acceptance testing. Secrets never belong in Git or browser JavaScript.

Routes /api/whatsapp/inbound and /api/whatsapp/status validate signatures and the exact channel/sender. SMS callbacks remain separate.
